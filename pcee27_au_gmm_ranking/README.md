# Ranking ground-motion models for Australia using the updated Australian Ground-Motion Database

This archive provides provides the <i>L</i><sub>2</sub> distances for the evaluated ground-motion models (GMMs) across geographical clusters at period of [0.2](https://github.com/GeoscienceAustralia/ga-earthquake-hazard/blob/master/pcee27_au_gmm_ranking/L2_heatmaps/L2_distance_period_0p2s.png), [0.5](https://github.com/GeoscienceAustralia/ga-earthquake-hazard/blob/master/pcee27_au_gmm_ranking/L2_heatmaps/L2_distance_period_0p5s.png) and [1.0](https://github.com/GeoscienceAustralia/ga-earthquake-hazard/blob/master/pcee27_au_gmm_ranking/L2_heatmaps/L2_distance_period_1p0s.png) s as described in _Ghasemi, H., and T. I. Allen (2027). Ranking ground-motion models for Australia using the updated Australian Ground-Motion Database_, presented at the Pacific Conference on Earthquake Engineering, Te Pae, Christchurch, New Zealand, 16-18 February 2027.

The departure from the standard normal distribution was quantified using the Euclidean (<i>L</i><sub>2</sub>) distance between the fitted and standard-normal probability density functions. For each response spectral period, the [heatmaps](https://github.com/GeoscienceAustralia/ga-earthquake-hazard/blob/master/pcee27_au_gmm_ranking/L2_heatmaps) show the <i>L</i><sub>2</sub> distance for the evaluated GMMs across geographical clusters as defined in [Allen (2026)](https://pubs.geoscienceworld.org/ssa/bssa/article/doi/10.1785/0120260045/733824/Systematic-Estimation-of-Earthquake-Source). The colour and values within each cell indicate the <i>L</i><sub>2</sub> distance from the ideal standard normal distribution. Smaller values indicate better overall agreement between a GMM and the observations, whereas larger values indicate greater departure in the location and/or spread of the residual distribution. The variable n is the number of available events in each cluster. The GMM naming convention is the same as that used in the [OpenQuake-engine hazardlib](https://github.com/gem/oq-engine/tree/master/openquake/hazardlib/gsim). Cluster 6 is omitted due to a lack of applicable records.

The standard normal distributions for each GMM and each cluster are provided [here](https://github.com/GeoscienceAustralia/ga-earthquake-hazard/blob/master/pcee27_au_gmm_ranking/standard_normal_distributions).
