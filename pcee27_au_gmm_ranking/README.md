# Ranking ground-motion models for Australia using the updated Australian Ground-Motion Database

This archive provides provides the <i>L</i><sub>2</sub> distances for the evaluated ground-motion models (GMMs) across geographical clusters at period of 0.2, 0.5 and 1.0 s as described in _Ghasemi, H., and T. I. Allen (2027). Ranking ground-motion models for Australia using the updated Australian Ground-Motion Database_, presented at the Pacific Conference on Earthquake Engineering, Te Pae, Christchurch, New Zealand, 16-18 February 2027.

For each response spectral period, the figures show the <i>L</i><sub>2</sub> distance for the evaluated GMMs across geographical clusters as defined in [Allen (2026)](https://pubs.geoscienceworld.org/ssa/bssa/article/doi/10.1785/0120260045/733824/Systematic-Estimation-of-Earthquake-Source). The colour and values within each cell indicate the <i>L</i><sub>2</sub> distance from the ideal standard normal distribution; n is the number of available events in each cluster. The GMM naming convention is the same as that used in the [OpenQuake-engine hazardlib](https://github.com/gem/oq-engine/tree/master/openquake/hazardlib). Cluster 6 is omitted due to a lack of applicable records.
